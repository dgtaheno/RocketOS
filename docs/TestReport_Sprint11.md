# Features Implemented

## 1. MAVLink HEARTBEAT

### Description

A periodic HEARTBEAT message is transmitted every second.

### Purpose

Allows Ground Control Stations to:

- Detect vehicle presence
- Monitor system status
- Verify link connectivity

### Result

✅ HEARTBEAT messages transmitted successfully

---

## 2. GPS_RAW_INT

### Description

GPS data generated by the NEO-M9N is encoded into MAVLink GPS_RAW_INT messages.

### Parameters Included

- Latitude
- Longitude
- Altitude
- Number of satellites
- GPS Fix Type
- HDOP

### Result

✅ GPS data successfully packed into MAVLink messages

---

## 3. GLOBAL_POSITION_INT

### Description

Vehicle position is exported through GLOBAL_POSITION_INT.

### Parameters Included

- Latitude
- Longitude
- Altitude
- Relative Altitude
- Ground Speed
- Heading

### Result

✅ Position telemetry successfully generated

---

## 4. Serial MAVLink Stream

### Description

All MAVLink messages are transmitted through the telemetry serial link.

### Result

✅ Stable communication observed

No communication lockups detected.

---

## 5. QGroundControl Preparation

### Description

QGroundControl was installed for future Ground Control Station testing.

### Goal
