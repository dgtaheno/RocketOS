# Defect Report – BATTERY_STATUS Pack Voltage

## Issue

QGroundControl reported an invalid battery pack voltage of **277.74 V**, while the INA219 measured **15.60 V** on the serial monitor.

State of charge (70 %) was reported correctly, confirming the sensor and battery monitor were functioning as expected.

## Root Cause

The `BATTERY_STATUS.voltages_ext[4]` array was initialized to `UINT16_MAX`.

Per MAVLink specification:

- `voltages[10]` — cells 1 to 10, in mV. Unused cells **must** be `UINT16_MAX`.
- `voltages_ext[4]` — cells 11 to 14, in mV. Unused cells **must** be `0`.

Ground control stations summed the extended cells into the reported pack voltage:

```text
4 x 65535 mV = 262.14 V

262.14 V + 15.60 V = 277.74 V
```

This matched the reported value exactly, confirming the root cause.

## Fix

- `voltages_ext[]` initialized to `0` for all unused cells
- `charge_state` changed from `MAV_BATTERY_CHARGE_STATE_UNDEFINED` to `MAV_BATTERY_CHARGE_STATE_OK` when the battery is connected
- Inline documentation added clarifying the difference between `voltages` and `voltages_ext`

## Verification

| Parameter | Before Fix | After Fix | Serial Reference | Result |
|------------|-----------|-----------|------------------|---------|
| Pack Voltage | 277.74 V | 15.30 V | 15.30 V | ✅ PASS |
| Remaining | 70 % | 62 % | 62 % | ✅ PASS |
| Charge State | Undefined | Ok | OK | ✅ PASS |

**Defect Status:** ✅ RESOLVED
